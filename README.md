# Tic-Tac-Toe Game in Java

A console-based, two-player Tic-Tac-Toe game developed using Java. The application allows two players to play alternately on a 3 × 3 grid, with automatic win and draw detection.

## Features

- **Two-Player Gameplay:** Supports two players taking alternate turns.
- **3 × 3 Game Board:** Displays the game board in a structured format.
- **Win Detection:** Checks rows, columns, and diagonals to identify winning combinations.
- **Draw Detection:** Identifies when all cells are occupied without a winner.
- **Input Validation:** Prevents invalid moves and ensures players select valid, unoccupied positions.
- **Turn Management:** Switches between players after each valid move.

## Getting Started

### Prerequisites

- Java Development Kit (JDK 8 or above)
- Any Java IDE or terminal

### Installation and Execution

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/tic-tac-toe.git
   ```

2. Navigate to the project directory:

   ```bash
   cd tic-tac-toe
   ```

3. Compile the Java source file:

   ```bash
   javac Main.java
   ```

4. Run the application:

   ```bash
   java Main
   ```

## How to Play

1. The game starts with an empty 3 × 3 board.
2. Player X makes the first move.
3. Player O plays in the next turn.
4. Players enter their chosen positions.
5. The game checks for a winning combination after every valid move.
6. The game ends when a player wins or the board is full, resulting in a draw.
